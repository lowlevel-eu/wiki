# C

C ist eine bekannte ältere Programmiersprache, mit dem Ziel, plattformunabhängig und akstrakter als [Assembler](https://github.com/lowlevel-eu/wiki/wiki/Assembler "Assembler"). Direkte Weiterentwicklung von C ist [C++](https://github.com/lowlevel-eu/wiki/wiki/C%2B%2B "C++").

# Kernelprogrammierung mit C

Da man mit C sehr hardwarenah programmieren kann(low-level), ist es möglich, mit C(ausser z.B. den Bootloader). Empfehlenstwerd ist, wie bei jeder Sprache, ein Compiler, der Inlineassembler kann, für die Kernelprogrammierung. Hierfür eignet sich der [gcc](https://github.com/lowlevel-eu/wiki/wiki/GNU-Compiler-Collection "Gcc")
