# Internet Protocol

Das Internet Protocol (IP) ist ein sehr weit verbreitetes Netzwerkprotokoll. Es ist die Grundlage des Internets, daher auch der Name. Ist wird sehr häufig zusammen mit dem Transfer Control Protocol (TCP) verwendet, dass auf dem IP aufbaut.

## Nutzen

In [Ethernetnetzwerken](https://github.com/lowlevel-eu/wiki/wiki/Ethernet "Ethernet") baut IP direkt auf Ethernet auf. Ethernetpakete können nur innerhalb eines LANs verschickt werden, da es zum Beispiel im Internet kein Ethernet gibt. Das IP ermöglicht es, Pakete in andere LANs oder über WANs (wie das Internet) zu verschicken, da die IP-Adresse eine logische und keine physikalische Adresse wie die MAC-Adresse ist. Daher muss keine direkte Verbindung zum Ziel bestehen, sondern nur eine logische, die über mehrere Zwischenstationen (z. B. Router) verlaufen kann. Mit Protokollen wie Ethernet können nur direkte Verbindungen (zum Beispiel zum Router) hergestellt werden.
