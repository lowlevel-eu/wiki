# Týndur/LostIOv2

Auf dieser Seite können Ideen und Wünsche für die neue LostIO-Version niedergeschrieben werden.

- **Integrierte FIFOs**, sodass beim Lesen mehr zurückgesendet werden kann, als gewünscht, das dafür beim nächsten Lesen dann dabei ist.
- **Blockierendes Lesen**
- **Etwas select()-artiges**
