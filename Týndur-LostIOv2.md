# Týndur/LostIOv2

Auf dieser Seite können Ideen und Wünsche für die neue [LostIO](https://github.com/lowlevel-eu/wiki/wiki/T%C3%BDndur-LostIO "LostIO")-Version niedergeschrieben werden.

- **Integrierte FIFOs**, sodass beim Lesen mehr zurückgesendet werden kann, als gewünscht, das dafür beim nächsten Lesen dann dabei ist.
- **Blockierendes Lesen**
- **Etwas select()-artiges**
- **ioctl()**
- **fcntl()**
- **Verschiedene Weitere Geräte. (Nullgerät, Randomgerät, RAM-Gerät, u.ä. (siehe /dev/)**
