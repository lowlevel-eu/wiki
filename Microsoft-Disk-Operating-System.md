# Microsoft Disk Operating System

MS-DOS(**M**icrosoft **D**isk **O**perating **S**ystem) ist eines der ersten Betriebssysteme für x86-PCs. DOS war in den späten 1980ern das dominierende Betriebssystem für Ein-Benutzer-Rechner. Heute ist DOS nicht mehr erhältlich. Stattdessen gibt es Betriebssysteme wie Free-DOS oder andere Abstammungen von MS-DOS. Alle Versionen von Windows waren abhängig von DOS; Beim NT-Kernel, der von neueren Windows-Versionen benutzt wurde, änderte sich dies: Der [NT](https://github.com/lowlevel-eu/wiki/wiki/Windows "NT")-[Kernel](https://github.com/lowlevel-eu/wiki/wiki/Kernel "Kernel") wurde komplett neu entwickelt und konnte DOS-Anwendungen nicht mehr oder mit Problemen starten. Ab diesem Zeitpunkt wurden immer häufiger Emulatoren eingesetzt, um diese Programme dennoch zu starten.
