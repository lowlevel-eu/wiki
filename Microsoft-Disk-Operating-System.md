# Microsoft Disk Operating System

**MS-DOS** (Microsoft Disk Operating System) ist eines der ersten Betriebssysteme für [x86](https://github.com/lowlevel-eu/wiki/wiki/X86 "X86")-PCs. DOS war in den späten 1980ern das dominierende Betriebssystem für Ein-Benutzer-Rechner. Heute ist DOS nicht mehr erhältlich. Stattdessen gibt es Betriebssysteme wie Free-DOS oder andere Abstammungen von MS-DOS.

Früher waren alle Versionen von [Windows](https://github.com/lowlevel-eu/wiki/wiki/Windows "Windows") abhängig von DOS, bis Windows 3.11 wurden DOS und Windows sogar noch getrennt installiert. Beim NT-Kernel, der von neueren Windows-Versionen benutzt wird, änderte sich das aber: Der [NT](https://github.com/lowlevel-eu/wiki/wiki/Windows "NT")-[Kernel](https://github.com/lowlevel-eu/wiki/wiki/Kernel "Kernel") wurde komplett neu entwickelt und konnte DOS-Anwendungen nicht mehr oder nur mit Problemen starten. Ab diesem Zeitpunkt wurden immer häufiger Emulatoren wie z.B. DOS-Box eingesetzt, um diese Programme dennoch starten zu können.
