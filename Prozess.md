# Prozess

Diese Seite ist ein Artikel, welcher **mehr** haben könnte..  

Wenn du mehr darüber weißt oder recherchieren willst, bist **du** aufgerufen, dies zu tun. Wenn du dir in einer Sache nicht sicher bist, dann stell es auf die Diskussionsseite.

Unter **Prozess** (auch Task genannt) versteht ein sich in der Ausführung befindendes Programm (d.h. im RAM liegend und evt. auf Ausführung wartend), welches vom Betriebssystem in Form einer [Prozessliste](https://github.com/lowlevel-eu/wiki/wiki/Prozessverwaltung "Prozessverwaltung") verwaltet wird.

  
Unter Prozess versteht man dabei gestartete Programme und Treiber, unter Thread versteht man in einem zusätzlichen Prozess ausgeführten Code eines Prozesses.
