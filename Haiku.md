## Haiku

Haiku ist ein OS das eine Reimplemntierung von BeOS sein sollte und dann mit weiteren Feautures erweitert wurde.

## Features

- SMP
- GUI
- AHCI
- BFS(Be File System)
- X64
- Radeon GraKA Treiber(Diese können einen eigenen Grafikmodus aufsetzen und unterstützen sogar teilweise Multi monitor und 2D Beschleunigung)
