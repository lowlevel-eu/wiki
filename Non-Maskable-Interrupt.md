# Non Maskable Interrupt

Ein NMI (**N**on **M**askable **I**nterrupt) ist ein Hardware[interrupt](https://github.com/lowlevel-eu/wiki/wiki/Interrupt "Interrupt"), welcher nicht (über das IE Flag im EFlags- bzw. RFlagsregister) gesperrt werden kann. Er kann jedoch über das höchste Bit im [CMOS](https://github.com/lowlevel-eu/wiki/wiki/CMOS "CMOS")-Adressregister ge- bzw. entsperrt werden. Er wird bei einem Hardware-Reset oder einem Hardwarefehler (z.B. Parity-Error beim RAM) ausgelöst.
