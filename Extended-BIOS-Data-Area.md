# Extended BIOS Data Area

Die **Extended BIOS Data Area** (Abkürzung: **EBDA**) dient dem BIOS als erweiterter Speicher, beispielsweise um die [SMP Floating Pointer Structure](https://github.com/lowlevel-eu/wiki/wiki/Symmetrisches-Multiprozessorsystem#floating-pointer-structure "SMP") zu speichern. Die [BIOS Data Area](https://github.com/lowlevel-eu/wiki/wiki/BIOS-Data-Area "BIOS Data Area") (Offset 0x0E) gibt darüber Auskunft an welcher Adresse im Speicher die EBDA liegt.
