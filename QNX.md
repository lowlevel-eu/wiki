# QNX

{Vorlage:Infobox OS\| Name = QNX\| Entwickler = QNX Software Systems \| Version = Neutrino (im Desktop-Bereich)\| Lizenz = Proprietär\| Plattform = [x86](https://github.com/lowlevel-eu/wiki/wiki/X86 "X86"), Power PC, X-Scale und weitere\| Binaerformat = ?\| Kernel = [Kernel#Mikrokernel](https://github.com/lowlevel-eu/wiki/wiki/Kernel#mikrokernel "Kernel")\| Homepage = [\[1\]](http://www.qnx.com/)\| Sprache = C\| }} QNX ist ein kommerzielles Mikrokernel-Betriebssystem der Firma [Harman International](http://de.wikipedia.org/wiki/Harman_International_Industries_Inc.) . QNX wurde ursprünglich nicht für den Desktopbereich, sondern für eingebettete Systeme entwickelt. Später entstand jedoch die Version "QNX RTOS" bzw. "QNX Neutrino" als Echtzeit-Betriebssystem mit [GUI](https://github.com/lowlevel-eu/wiki/wiki/Graphical-User-Interface "GUI").
