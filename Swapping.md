# Swapping

Diese Seite ist ein Artikel, welcher **mehr** haben könnte..  

Wenn du mehr darüber weißt oder recherchieren willst, bist **du** aufgerufen, dies zu tun. Wenn du dir in einer Sache nicht sicher bist, dann stell es auf die Diskussionsseite.

Unter **Swapping** versteht man das Auslagern von Dateien, die nicht mehr ins RAM passen in eine externe Datei auf einer Festplatte o.ä.. Dabei wird das Swapfile genau angesprochen wie der Arbeisspeicher, dementsprechend müssen die Filesystem-Informationen gemappt werden.
