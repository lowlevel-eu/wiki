In der Mache.

  
CORE.\OS ist ein [Betriebssystem](https://github.com/lowlevel-eu/wiki/wiki/Betriebssystem "Betriebssystem"), welches von MtheD entwickelt wird. Es befindet sich zur Zeit in einem sehr frühen Stadium. Hauptziel von CORE.\OS ist es, eine benutzbare Umgebung für Entwickler bereitzustellen. Vom Bedienungskonzept her wird CORE.\OS neue Wege gehen.

## Features

CORE.\OS bietet einige Features (bzw. soll sie bieten). Einige Beispiele:

- CORE.\BOOT (Eigener Bootmanager)
- CORE.\\LOTUS" (Graphische Benutzeroberfläche)
- Speichermedien: Festplatte, CD-ROM, Diskette
- Dateisysteme: CORE.\FS, [FAT](https://github.com/lowlevel-eu/wiki/wiki/File-Allocation-Table "FAT"), [ISO9660](https://github.com/lowlevel-eu/wiki/wiki/ISO9660 "ISO9660")
- Eigene Programme:
  - CORE.\TERMINAL (Shell)
  - CORE.\TXT (TextEditor)
  - CORE.\PCKG (Paketmanager)
  - CORE.\EDIT (Integrierte Entwicklungsumgebung mit CORE.\SCRPT)
  - CORE.\CLOUD (Cloud-Computing-Service für Entwickler)
  - CORE.\WEB (Webbrowser)
  - Weiteres folgt...
- CORE.\KRNL (Kernel):
  - Multitasking
  - Protected Mode
  - Pagging
  - Physische Speicherverwaltung
  - Interprozesskommunikation
  - Weiteres folgt...
- Und vieles mehr...
