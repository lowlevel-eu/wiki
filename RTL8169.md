# RTL8169

Diese Seite ist ein Artikel, welcher **mehr** haben könnte..  

Wenn du mehr darüber weißt oder recherchieren willst, bist **du** aufgerufen, dies zu tun. Wenn du dir in einer Sache nicht sicher bist, dann stell es auf die Diskussionsseite.

Der RTL8169 ist neben dem [RTL8139](https://github.com/lowlevel-eu/wiki/wiki/RTL8139 "RTL8139") ein weiterer Netzwerkchip der Firma Realtek. Er kann Daten im Bereich von 10/100/1000 Megabits pro Sekunde übertragen.

## MAC-Adresse herausfinden

Die MAC-Adresse des Geräts besteht aus 6 "Einzelteilen" und ist 6 Bytes lang. Die Adresse, unter die MAC-Adresse erfragt werden kann, ist nicht genau festgelegt und muss daher vom [PCI](https://github.com/lowlevel-eu/wiki/wiki/Peripheral-Component-Interconnect "PCI")-Treiber herausgefunden werden. Wenn man die Basisadresse hat, kann man mit folgendem Code die MAC-Adresse herausfinden:

\<c\> int i; char mac_addr\[6\]; for(i = 0; i \< 6; ++i) {

       mac_addr = inb(pci_port + i); //Funktion zum Einlesen eines Bytes vom angegebenen Port

} \</c\>

Nun ist die MAC-Adresse in dem char-Array gespeichert.
