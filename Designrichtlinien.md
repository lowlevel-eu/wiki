# Designrichtlinien

Aufgrund der Tatsache, dass die Artikel manchmal doof wirkt, finde ich sollten, gewisse Designrichtlinien eingeführt werden. Regeln können ergänzt werden.

## Mediawikicode

- Artikel zu Kategorien immer mit *Kategorie: Kategoriename* einordnen, nicht mit *Category: Kategoriename*
- C bzw. Assembler-Beispielcode mit c bzw. asm taggen. Sieht schöner aus, siehe Beispiel.

\<c\> int main(){ int Test1; int Test2; Test2 = 1000; Test1 = 500: int Ergebnis = Test1 \* Test2 ^ 2; }\</c\>

## Artikelaussehen

- Möglichst viel verlinken
- Wo zwei Artikelnamen in ein Wort stecken, garnichts verlinken(z.B. C-Kernel, nicht auf C und Kernel verlinken([`C`](https://github.com/lowlevel-eu/wiki/wiki/C "C")`-`[`Kernel`](https://github.com/lowlevel-eu/wiki/wiki/Kernel "Kernel")))
- *Siehe auch*-Kapitel für interne intressante Wikilinks
- *Weblinks*-Kapitel für Weblinks
