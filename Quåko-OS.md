**Quåko OS** ist ein Hobby-OS, welches Zeilenbasiert ist und in den Sprachen C, C++ und Assembler geschrieben ist. Die erste Version wird 0.1 heißen, die ist gerade in Produktion. Sie kommt wahrscheinlich noch am Silvester oder erst Anfang Januar raus und wird zu einem kostenlosen Download verfügbar sein. Der Source Code wird auch frei verfügbar sein. Das OS und der Source Code wird sich in einer 7-Zip Datei befinden. Der Boot wird vom Diskettenlaufwerk erfolgen. Ich werde auch Assembler in einer C, oder C++ Datei benutzen(z.B.:Video-Interrupt, da die Funktion int86() veraltert ist).
