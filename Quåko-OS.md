**Quåko OS** ist ein Hobby-OS, welches Zeilenbasiert ist und in der Sprache NASM geschrieben ist. Die erste Version wird 0.1 heißen, die ist gerade in Produktion. Sie kommt wahrscheinlich noch am Silvester oder erst Anfang Januar raus und wird zu einem kostenlosen Download verfügbar sein. Der Source Code wird auch frei verfügbar sein. Das OS und der Source Code wird sich in einer 7-Zip Datei befinden. Der Boot wird vom Diskettenlaufwerk erfolgen.
