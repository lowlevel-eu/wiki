# NT

Windows NT oder vielmehr der NT-Kernel wird in allen neuen Betriebssystemen von Microsoft eingesetzt. Der Name bedeutete anfangs NTen. Das war der Name einer Prozessorarchitektur, für diese NT anfangs entwickelt wurde. Der Name wurde später auf New Techlogy umgedeutet
