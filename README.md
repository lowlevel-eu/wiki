# Lowlevel-Wiki

Willkommen im Wiki der Lowlevel-Community! Hier sammeln wir Wissen rund um die
Entwicklung eigener Betriebssysteme – vom ersten Bootsektor bis zum eigenen
Kernel.

**[Wiki lesen](https://github.com/lowlevel-eu/wiki/wiki)** ·
[Artikel im Repository](pages/Home.md) ·
[Fragen und Diskussionen](https://github.com/lowlevel-eu/wiki/discussions)

Du möchtest etwas verbessern oder ergänzen? Die Artikel und Bilder liegen unter
[`pages/`](pages/). Änderungen werden hier per Pull Request besprochen und nach
dem Merge automatisch im Wiki veröffentlicht. Wie das geht, steht in
[CONTRIBUTING.md](CONTRIBUTING.md).

Die ursprünglichen Bearbeitungen und Autorennamen bleiben in der Git-Historie
erhalten. Das [alte Wiki samt Versionsgeschichte und das Forum](https://lowlevel-eu.github.io/)
bleiben als schreibgeschütztes Archiv verfügbar.
