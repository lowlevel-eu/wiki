# Non-Uniform Memory Architecture

NUMA (**N**on-**U**niform **M**emory **A**ccess) ist eine Speicherarchiktektur für Multiprozessorsysteme, dessen Zugriffszeiten auf den Arbeitsspeicher vom Ort des Arbeitsspeichers und der CPU abhängen.
