# Non-Uniform Memory Architecture

NUMA (**N**on-**U**niform **M**emory **A**rchitecture) ist eine Speicherarchiktektur für Multiprozessorsysteme, dessen Zugriffszeiten auf den Arbeitsspeicher vom Ort des Arbeitsspeichers und der CPU abhängen.
