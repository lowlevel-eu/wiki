# Týndur/Roadmap

Features die kursiv geschrieben sind, sind noch gar nicht, oder nur teilweise implementiert.

# Version 0.1.x (Morgoth)

## Version 0.1.0

- **Feature Freeze:** 09.04.2007
- **Release Termin:** 03.05.2007

Features:

- Speicherverwaltung
- Multitasking
- Einfache Interprozesskommunikation
- [LostIO](T%C3%BDndur-LostIO.md "LostIO") soweit für einfache Dateioperationen nötig
- DMA & Diskettenlaufwerk
- FAT12:
  - Anlegen von Dateien und Verzeichnissen
  - Lesen und Schreiben in Dateien
- Tastatur
- Konsole
- Einfache Shell

## Version 0.1.1

- **Release:** 24.12.2007

Features und Verbesserungen:

- Optimierte RPC-Funktionen
- Pufferung in LostIO
- Kernelseitige Kontrolle der IO-Ports
- FAT12

# Version 0.2.0 (Gothmog)

- **Release:** 24.12.2008

Features

- Virtuelle Terminals
- Treiber für ata und ext2
- Paketverwaltung lpt
- Pakete wie binutils, fpc (FreePascal), gcc und nano
- Netzwerkunterstützung mit Treiber für rtl8139 und sis900
- Tab-Completion und andere neue Möglichkeiten zum editieren der Kommandozeile in der Shell
- Editor kedit verbessert; neu ist unter anderem das Syntax-Highlighting für C (einschalten mit F8)

# Version 0.3.x

- *kernel2*
  - Unterstützung für i386 und *amd64*
  - *SMP*
- *[LostIO v2](T%C3%BDndur-LostIOv2.md "Týndur/LostIOv2")*
