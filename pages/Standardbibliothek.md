# Standardbibliothek

Diese Seite ist ein Artikel, welcher **mehr** haben könnte..  

Wenn du mehr darüber weißt oder recherchieren willst, bist **du** aufgerufen, dies zu tun. Wenn du dir in einer Sache nicht sicher bist, dann stell es auf die Diskussionsseite.

Die meisten Programmiersprachen haben eine Standardbibliothek, die einige Funktionen bereitstellt die Programme immer nutzen können. Für C wird diese z.B. üblicherweise `libc` genannt. Damit die Sprache wie gewohnt im Userspace des eigenen Betriebssystems benutzt werden kann, muss sie (oder eine ihrer Implementierungen) für das Betriebssystem portiert werden.

## Beispiele

Hier sind nun ein paar Implementierungen aufgelistet.

### C

- Glibc
- Newlib
  - wird häufig für Hobby-OS verwendet da recht einfach zu portieren

### C++

- GNU libstdc++
- LLVM/Clang libc++
  - erfolgreich für LF OS portiert
