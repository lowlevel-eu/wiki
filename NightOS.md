NightOS hat die Aufgabe einen PC schnell und einfach zu benutzen. Die Shell wird als .elf Datei von GRUB geladen.  

## Features

### 0.0.1

- Interrupts funktionieren
- Tastaturtreiber
- ganz kleine Shell

### 0.0.2 (voraussichtlich)

- Interrupts funktionieren
- Tastaturtreiber
- Multitasking
- ELF-Loader
- ~~ganz~~ kleine Shell

### 0.0.3 (voraussichtlich)

- Interrupts funktionieren
- Tastaturtreiber
- Multitasking
- ELF-Loader
- ~~ganz kleine~~ Shell
- Floppy-Treiber
- FAT12-Treiber
