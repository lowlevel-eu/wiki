Linux ist ein freies Betriebsystem und steht in Konkurrenz zu [Windows](https://github.com/lowlevel-eu/wiki/wiki/Windows "Windows") .

## Die Entstehung

Linux entstand 1991 durch den damaligen Informatikstudent Linus Torvalds an der Universität von Helsinki unter dem Namen "Freax". Linux Torvalds besaß damals einen 386er mit installiertem Minix, und schrieb darauf einen Terminalemulator. Er fügte weitere Funktionen hinzu, wie Multitasking, Zugriff auf das Diskettenlaufwerk usw. Schließlich baute er das ganze zu einem Kernel aus, den er auf dem FTP-Server von xxx hochlud. Der Besitzer war mit dem Namen "Freax", den Linus für seinen Kernel gewählt hatte, nicht einverstanden, und legte den Kernel in das Verzeichnis "Linux".

## Bezeichnung von Linux

Wenn meistens von Linux gesprochen wird, dann meint man eine Distribution von Linux. Eigentlich ist Linux nur ein [Kernel](https://github.com/lowlevel-eu/wiki/wiki/Kernel "Kernel"). Wenn man von einer Linux-Distribution spricht, ist die korrekte Systembezeichnung eigentlich GNU/Linux, da der Großteil des Userlands aus dem GNU-Projekt stammt.

## Graphical User Interface

Unter Linux gibt es dutzende [GUIs](https://github.com/lowlevel-eu/wiki/wiki/Graphical-User-Interface "GUI"), die unternannder konkurieren. Am meisten verbreitet sind KDE und Gnome

## Das UNIX-Prinzip

Linux hat eine Eigenart von UNIX übernommen: Alles ist eine Datei. Das Diskettenlaufwerk zum Beispiel wird über /dev/fd0 angesprochen. Linux besitzt keine Laufwerksbuchstaben wie MS-DOS und Windows, die erste Festplatte (bei IDE) findet man unter /dev/hda.
