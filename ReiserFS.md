# ReiserFS

Diese Seite ist ein Artikel, welcher **mehr** haben könnte..  

Wenn du mehr darüber weißt oder recherchieren willst, bist **du** aufgerufen, dies zu tun. Wenn du dir in einer Sache nicht sicher bist, dann stell es auf die Diskussionsseite.

| ReiserFS |  |
| ---------------------------- | ------------------------------ |
| Entwickler: | Hans Reiser |
| Vollständige Bezeichnung: | Reiser File System |
| Maximalgröße einer Datei: | 1 EB (theoretisch unter 3.6) |
| Maximale Dateianzahl: | 2<sup>32</sup> − 3 |
| Länge des Dateinames: | Blockgröße - 64 |
| Maximale Dateisystemgröße: | 16 TB |
