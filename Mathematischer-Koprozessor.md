# Mathematischer Koprozessor

Ein mathematischer Koprozessor (oder FPU (**F**loating **P**oint **U**nit)ist eine extra Einheit einer CPU zum Berechnen von Gleitkommawerten. Die FPU verfügt dafür über breitere Register als normale CPUs (64, 69 oder 128 Bit) um höhere Genauigkeiten zu gewährleisten, sowie über spezielle Recheneinheiten für trigonometrische Berechnungen.
